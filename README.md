# FLAMES Game ❤️

FLAMES Game is a fun website where users enter two names to discover their relationship result using the traditional FLAMES game.

## Features
- Enter two names.
- Automatically calculate the FLAMES result.
- Display Friends, Love, Affection, Marriage, Enemies, or Siblings.
- Fun animations and attractive design.
- Reset and play again.

https://flames-game.ai.studio/

## Disclaimer
This game is only for fun and entertainment. The results are not real predictions.
